## How to read a status

- `green` — the namespace ran and every assertion passed.
- `red` — it ran and reported failures or errors: implemented, implemented wrong.
- `abort` — it never reported, or reported an empty run: not implemented at all.
- `timeout` — still running when the per-namespace deadline passed.
- `-` — that dialect has no measurement for that namespace.

Status is the only thing compared across columns. Each dialect counts in
its own unit — clojurust reports assertions, the `#counts` dialects report
test vars and assertions — so the counts above are per dialect and are
never summed across dialects.
